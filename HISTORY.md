Some recovered folders contain a different internal version label. Their code is retained as found, and SOURCE.json records the discrepancy. Tags identify the preserved folder checkpoint rather than inventing missing versions.

Imported commits have their actual publication dates. Historical validation reports describe original local runs; importing a checkpoint does not rerun or re-certify every historical version.

The separately supplied GPIO-expander sketch is in `firmware/gpio_expander.ino`. Its original folder is not treated as an app release.
